RSMesh BBS Changelog
====================

Release 1.1 (in development)
------------------------------

Mesh user interface
  - Main menu layout: [B]ulletins / [C]hannels, [M]ail / M[O]dules, E[X]IT
  - Read Mail and Send Mail moved under [M]ail submenu ([R] / [S])
  - Modules aggregator key changed from M to O (M[o]dules)
  - Main menu option rows cached in mesh_ui/main_menu.txt (title line built at display time)
  - Disabled core service keys remain on the menu for optional module overrides
  - Empty mail inbox returns to the mail submenu instead of the main menu
  - Per-module main_menu_visible flag promotes module keys to the main menu
  - bbs.suppress_modules_menu hides the M[o]dules aggregator when all modules are promoted
  - M[o]dules hidden when no enabled modules need the aggregator submenu
  - Invalid or oversized main_menu.txt falls back to auto-generated body (200-byte mesh limit)
  - Admin: Regenerate Main Menu; Edit Module Flags includes Show on main menu
  - Module menu_option validation rejects reserved keys B, C, M, O, X, R, S

Mesh client (rsmesh-bbs_client.py)
  - --verbose / -v: print (no reply) when the BBS sends no response (default silent)

Core Services (admin)
  - Administration -> Core Services toggles for Bulletins, Mail, and Channels
  - Settings stored in sys_config (bbs.core_bulletins, bbs.core_mail, bbs.core_channels)
  - Seeded from config.yml; missing keys added on upgrade (default enabled)
  - Admin main menu hides Bulletins / Channels / Mail entries when the service is off
  - Disabled services skip inbound/outbound peer sync and scheduled purge for that type
  - List Unsynced Data omits record types for disabled core services

Sync (rsv1)
  - Bulletin ingest upserts by unique_id (tc2 remains insert-only)
  - Pinned bulletins sync via rsv1 pin field
  - Protocol differences documented in docs/RSMESH-BBS-DEVELOPER-GUIDE.md

Documentation
  - Sysop guide: docs/RSMESH-BBS-SYSOP-GUIDE.md (renamed from README-ADMIN.md)
  - Developer guide: docs/RSMESH-BBS-DEVELOPER-GUIDE.md
  - Mesh user guide: docs/RSMESH-BBS-USER-GUIDE.md
  - Module development merged into docs/RSMESH-BBS-DEVELOPER-GUIDE.md
  - Planned enhancements tracked in docs/TODO.txt

Release 1.0
-----------

Initial RSMesh BBS release (fork/evolution of TC2-BBS concepts)
  - Mesh mail, bulletins (General/Info/News/Urgent), and channel directory
  - tc2 and rsv1 peer sync, sync peer admin, reconcile workflows
  - Module framework (Node Info, Fortune, Example Hello)
  - Mesh client (rsmesh-bbs_client.py) for handset testing without radio
  - Admin tool with bulletins, mail, channels, mesh nodes, node catalog, backup
  - TC2 database/config migration path
