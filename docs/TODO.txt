      - Default: generate from current configuration (core services, modules on main menu,

      - Regenerate when operator changes core services, module flags, or uses admin action
      - Operator may edit the file directly for branding/layout; invalid/oversized file
        falls back to auto-generated content (200 bytes per mesh packet; multi-packet OK)
      - Admin: Administration -> Regenerate Main Menu (rewrites cache from current config)

      fixed title line in cached file and show mail count in a separate short line on HELP
    - Module keys on main menu (per-module flag, e.g. main_menu_visible on modules table)
      - Validate menu_option does not collide with core keys B, C, R, S, M, X
      - Dynamic main_menu_handlers dispatch (core handlers + module get_by_menu_option)
    - Suppress [M]odules submenu (global flag, e.g. bbs.suppress_modules_menu)

      - No enabled modules -> no [M]odules
      - All enabled modules on main menu AND suppress_modules_menu on -> no [M]odules
      - Show [M]odules when any enabled module is not on main menu, or when suppress
